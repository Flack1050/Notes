##   ⚙️ Arch System Administration
**----------------------------------------------------------**

---
###      🧩 1. systemd — управление                          службами (services)

**Что это:**
`systemd` — управляет службами которые работают в фоне: интернет (NetworkManager) SSH (`sshd`) Bluetooth display manager и т.д.

**Когда используется:**
Когда что-то не запускается, не работает, нужно включить автозагрузку или добавить/обновить unit-файл.

---
####        🔎 Проверка состояния службы

``` bash
systemctl status service_name
```

**📌 Используется если:**

- не работает интернет
    
- не запускается `sshd`
    
- bluetooth не включается

---
####      ▶️ Запуск / остановка / перезапуск

``` bash
sudo systemctl start service_name
sudo systemctl stop service_name
sudo systemctl restart service_name
```

**📌 Используется:**

- после изменения конфигурации
    
- после установки сервиса
    
- если служба зависла

---
###                  🚀 Автозагрузка               (включить/отключить автозапуск)

``` bash
sudo systemctl enable service_name
sudo systemctl disable service_name
```

**📌 Используется:**

- чтобы сервис автоматически запускался при загрузке системы

---
####      🔁 Перезагрузить systemd конфиги

``` bash
sudo systemctl daemon-reload
```

**📌 Используется:**

- после изменения/добавления unit-файлов (`.service` `.timer` и т.д.). Без этого новые/изменённые юниты systemd не увидит.

---
####                 📋 Полезные команды

``` bash
systemctl list-units --type=service
systemctl list-unit-files
```

*Показывают активные юниты и файлы юнитов соответственно.*

---
###        📜 2. journalctl — просмотр                             логов systemd

**Что это:**  
`journalctl` — показывает логи системы и служб: запуски ошибки падения предупреждения твой главный инструмент диагностики.

**Когда используется:**

- служба не запускается
    
- система загрузилась с ошибками
    
- после обновления что-то сломалось
    
- нужно понять причину сбоя

---
####            🔎 Логи конкретной службы

``` bash
journalctl -u service_name
```

**📌 Используется:**  
Когда служба (например `sshd` `NetworkManager` `bluetooth`) падает или не стартует.

**Пример:**

```bash
journalctl -u sshd
```

*Покажет почему SSH не запускается.*

---
####         📡 Логи конкретной службы в                               реальном времени

``` bash
journalctl -u service_name -f
```

**📌 Используется:**  
Чтобы наблюдать логи конкретного сервиса “вживую” при отладки/запуске.

---
####              🔄 Логи текущей загрузки

``` bash
journalctl -b
```

**📌 Используется:**  
Если после перезагрузки система ведёт себя странно — показывает логи с момента последней загрузки.

---
####           ❌ Показать только ошибки                                 текущей загрузки

``` bash
journalctl -p 3 -xb
```

**📌 Используется:**  
Быстрая фильтрация: `-p 3` = ошибки `-x` = доп. пояснения `-b` = текущая загрузка.

---
####           📂 Логи предыдущей загрузки

``` bash
journalctl -b -1
```

**📌 Используется:**  
Если систему упало/зависла в прошлый раз — посмотреть что было тогда.

---
####              🧾 Ограничение вывода

``` bash
journalctl -n 50
```

*Показать последние 50 строк — удобно при большом количестве логов.*

###      👤 3. Пользователи и группы

**Что это:**  
Linux — многопользовательская ОС. Управление пользователями и группами — базовая админская задача.

**Когда используется:**

- создавать нового пользователя после установки
    
- настраивать sudo/права доступа
    
- готовить акаунты для сервисов или коллег

---
####              ➕ Создать пользователя

``` bash
sudo useradd -m username
sudo passwd username
```

**📌 Используется:**  
При создании обычного аккаунта. `-m` создаёт `/home/username`.

---
####              ➖ Удалить пользователя

``` bash
sudo userdel -r username
```

**📌 Используется:**  
Удаление аккаунта и домашней папки (`-r`) при очистке.

---
####                👥 Добавить в группу                               (например wheel для sudo)

``` bash
sudo usermod -aG wheel username
```

**📌 Используется:**  
Чтобы дать пользователю права sudo (после убедиться что `wheel` разрешён в `/etc/sudoers`).

---
####      ✅ Проверить группы пользователя

``` bash
groups username
```

**📌 Используется:**  
Убедиться, что пользователь в нужных группах (например в `wheel`).

---
####              📋 Список пользователей

``` bash
cat /etc/passwd
```

**📌 Используется:**  
Быстрая проверка наличия аккаунтов и системных пользователей.

---
###               🔑 4. Права доступа                                 (chmod / chown)

**Что это:**  
Контроль доступа к файлам и директориям (кто читаe/пишe/запускаe).

**Когда используется:**

- ошибка `Permission denied`
    
- скрипт не запускается
    
- веб-сервер или сервис не видит файл 

---
####          ▶ Сделать файл исполняемым

``` bash
chmod +x script.sh
```

**📌 Используется:**  
Если скрипт не запускается по причине отсутствия флага исполнения.

---
####              👤 Изменить владельца

``` bash
sudo chown user:group file
```

**📌 Используется:**  
Когда сервис (например `nginx`/`www-data`) должен иметь доступ к файлу или директории.

---
####            🔢 Изменить права числом

``` bash
chmod 755 file
```

**📌 Что значит 755:**

- 7 = rwx (владелец)
    
- 5 = r-x (группа)
    
- 5 = r-x (остальные)

*Используется часто для скриптов и директорий.*

---
####      🔍 Посмотреть права и владельца

``` bash
ls -l path
```

**📌 Используется:**  
Чтобы понять почему `Permission denied` — сначала смотри `ls -l`.

---
###         🖥 5. Управление системой           (перезагрузка, память, нагрузка)

**Что это:**  
Базовые команды для контроля состояния ОС.

**Когда используется:**

- после обновления ядра или драйверов
    
- при подозрениях на нехватку ресурсов
    
- при зависании системы

---
####                     🔄 Перезагрузка

``` bash
sudo reboot
```

**📌 Используется:**  
После обновления ядра драйверов или больших конфигурационных изменений.

---
####                       ⛔ Выключение

``` bash
sudo poweroff
```

**📌 Используется:**  
Корректное завершение работы машины.

---
####          ⏱ Проверка времени работы

``` bash
uptime
```

**📌 Используется:**  
Узнать когда система была перезагружена в последний раз.

---
####             💾 Использование памяти

``` bash
free -h
```

**📌 Используется:**  
Если система тормозит — проверяем RAM.

---
####               📊 Нагрузка / процессы

``` bash
top
htop
```

**📌 Используется:**  
Найти процессы грузящие CPU или память.

*`htop` — удобнее но требует установки.*

---
####              💽 Использование диска

``` bash
df -h
```

**📌 Используется:**  
Проверить заполнение разделов — полон диск часто вызывает ошибки и проблемы при обновлениях.

---
###                   🧠 6. Важные                               конфигурационные файлы

**Что это:**  
Файлы где хранятся ключевые настройки системы.

**Когда меняются:**  
При смене имени хоста, локали репозиториев initramfs и т.д.

---
####                  🖥 `/etc/hostname`

**📌 Используется:**  
Изменить имя компьютера.

---
####                    🌐 `/etc/hosts`

**📌 Используется:**  
Добавить локальные домены или сопоставить IP → имя (локальное решение проблем с hostname).

---
####              🌍 `/etc/locale.gen`

**📌 Используется:**  
Выбрать локали (языки). После изменений выполнить:

``` bash
sudo locale-gen
```

---
####              📦 `/etc/pacman.conf`

**📌 Используется:**  
Включить `multilib` добавить сторонние репозитории настроить поведение pacman.

---
####            🧱 `/etc/mkinitcpio.conf`

**📌 Используется:**  
Настройка initramfs (модули хуки) — важно при LUKS/LVM/особых драйверах. После изменений:

``` bash
sudo mkinitcpio -P
```

---
###                 🧱 7. Модули ядра

**Что это:**  
Драйверы которые можно загружать динамически (без перезагрузки ядра).

**Когда используется:**

- Wi-Fi адаптер не работает
    
- VirtualBox модули не загружены
    
- видеодрайвер нужно подгрузить вручную

---
####                  📥 Загрузить модуль

``` bash
sudo modprobe module_name
```

**📌 Используется:**  
Чтобы загрузить драйвер в рантайме.

---
####     📋 Посмотреть загруженные модули

``` bash
lsmod
```

**📌 Используется:**  
Проверить загружен ли нужный модуль.
