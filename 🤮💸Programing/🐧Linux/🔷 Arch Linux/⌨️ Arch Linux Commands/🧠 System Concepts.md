---
###           🖥 1. Kernel / Ядро Linux

**Что это:**  
Ядро — сердце системы. Оно управляет железом процессами памятью драйверами.  
Без ядра Linux просто не существует.

**Когда используется:**

- При загрузке системы
    
- Когда драйверы подключаются (видеокарта Wi-Fi USB)
    
- При работе с процессами и памятью

**Полезные команды:**

``` bash
uname -r
cat /proc/version
lsmod 
modprobe module_name
```

|      **Команда**       |    **Значения**    |
| :--------------------: | :----------------: |
|       `uname -r`       |    Версия ядра     |
|  `cat /proc/version`   |    Детали ядра     |
|        `lsmod`         | Загруженные модули |
| `modprobe module_name` | Загрузить драйвер  |

---
###          🗂 2. Файловая система

**Что это:**  
Структура хранения файлов. В Linux всё — файл (устройства конфиги обычные файлы).

**Главные моменты:**

- `/` — корень
    
- `/home` — домашние папки пользователей
    
- `/etc` — конфигурации
    
- `/var` — переменные данные, логи
    
- `/usr` — программы и библиотеки

**Когда используется:**

- Чтобы понять где что лежит
    
- Настройка прав доступа и владельцев
    
- Монтирование новых дисков/разделов

**Команды:**

``` bash
lsblk
df -h
mount /dev/sdX /mnt
umount /mnt
```

|      **Команда**      |       **Значения**       |
| :-------------------: | :----------------------: |
|        `lsblk`        | Список дисков и разделов |
|        `df -h`        |   Использование диска    |
| `mount /dev/sdX /mnt` |    Монтировать раздел    |
|     `umount /mnt`     |      Размонтировать      |

---
###                  ⚙️ 3. Процессы

**Что это:**  
Каждая запущенная программа — процесс. Он потребляет CPU и память.

**Когда используется:**

- Проверка «что грузит систему»
    
- Остановка зависших приложений
    
- Настройка автозапуска

**Команды:**

``` bash
ps aux
top / htop
kill PID
```

| **Команда**  |          **Значения**          |
| :----------: | :----------------------------: |
|   `ps aux`   |     Список всех процессов      |
| `top / htop` | Динамический просмотр нагрузки |
|  `kill PID`  |      Убить процесс по PID      |

**Примечание:**  
Процессы имеют владельца права и могут запускаться в фоне (daemon / service).

---
###        🧠 4. Пользователи и права

**Что это:**  
Механизм который разделяет доступ к файлам и ресурсам.  
Root = суперпользователь обычный юзер = ограниченный.

**Когда используется:**

- Установка программ и сервисов
    
- Защита системы от случайных изменений
    
- Совместная работа на сервере

**Команды:**

``` bash
id username
groups username
sudo command
chmod 755 file
chown user:group file
```

|       **Команда**       |   **Значения**    |
| :---------------------: | :---------------: |
|      `id username`      |    UID группы     |
|    `groups username`    |  В каких группах  |
|     `sudo command`      | Выполнить от root |
|    `chmod 755 file`     |   Права доступа   |
| `chown user:group file` |  Смена владельца  |
|                         |                   |

###                 🖧 5. Сеть в Linux

**Что это:**  
Все сетевые интерфейсы (Ethernet Wi-Fi) управляются ядром + сетевыми службами (NetworkManager systemd-networkd).

**Когда используется:**

- Настройка интернет-соединения
    
- Работа с SSH веб-серверами прокси
    
- Проверка и диагностика сетевых проблем

**Команды:**

``` bash
ip a
ping google.com
ss -tuln
nmcli device status
```

|      **Команда**      |            **Значения**             |
| :-------------------: | :---------------------------------: |
|        `ip a`         |        Посмотреть интерфейсы        |
|   `ping google.com`   |        Проверить соединение         |
|      `ss -tuln`       |          Порты и прослушка          |
| `nmcli device status` | Статус интерфейсов (NetworkManager) |

###            📦 6. Пакетная система

**Что это:**  
Менеджер пакетов (pacman yay paru) хранит информацию о программах их версиях и зависимостях.

**Когда используется:**

- Установка / удаление программ
    
- Обновление системы (rolling release)
    
- Проверка целостности пакетов

**Команды:**

``` bash
pacman -Q
pacman -Syu 
pacman -R package
```

|     **Команда**     |     **Значения**     |
| :-----------------: | :------------------: |
|     `pacman -Q`     | Установленные пакеты |
|    `pacman -Syu`    |  Обновление системы  |
| `pacman -R package` |       Удаление       |

---
###         🧱 7. Модули и драйверы

**Что это:**  
Расширения ядра для работы с железом. Модули можно подключать и выгружать динамически.

**Когда используется:**

- Подключение нового оборудования
    
- Исправление проблем с Wi-Fi / видео / USB
    
- Настройка VirtualBox / Docker

**Команды:**

``` bash
lsmod
modprobe name
rmmod name
```

|   **Команда**   |    **Значения**    |
| :-------------: | :----------------: |
|     `lsmod`     | Загруженные модули |
| `modprobe name` |  Загрузить модуль  |
|  `rmmod name`   |  Выгрузить модуль  |

---
###      📝 8. Конфигурации системы

**Что это:**  
Файлы которые управляют поведением Linux и программ.

**Главные файлы:**

|           **Файл**            |   **Назначение**    |
| :---------------------------: | :-----------------: |
|         /etc/hostname         |     Имя системы     |
|          /etc/hosts           |  Локальные домены   |
|        /etc/locale.gen        | Языки и локализация |
|       /etc/pacman.conf        |  Настройки pacman   |
| /etc/systemd/system/*.service | unit-файлы systemd  |

**Когда используется:**

- Настройка сети
    
- Добавление автозапуска сервисов
    
- Изменение поведения приложений

---
###              ⚡ 9. Logging / Логи

**Что это:**  
Система записывает события — кто что сделал ошибки предупреждения.  
`journalctl` — основной инструмент просмотра логов systemd.

**Когда используется:**

- Диагностика проблем
    
- Разбор ошибок пакетов / сервисов
    
- Мониторинг безопасности

**Команды:**

``` bash
journalctl -b -1
journalctl -u service
journalctl -f
```

|       **Команда**       |      **Значения**       |
| :---------------------: | :---------------------: |
|   `journalctl -b -1`    |   Предыдущая загрузка   |
| `journalctl -u service` |    Конкретная служба    |
|     `journalctl -f`     | Логи в реальном времени |

---
###         🧰 10. Основная идея Linux

1. Всё — файл (устройства процессы конфиги).
    
2. Пользователи и права — ключ безопасности.
    
3. Службы (systemd) делают систему живой.
    
4. Ядро управляет железом и памятью.
    
5. Логи и пакетная система — твои главные инструменты админа.

> Если ты понимаешь это на базовом уровне — уже не боишься Linux и можешь отлаживать почти всё.
