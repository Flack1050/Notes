##            🔐 Security & Firewall
**----------------------------------------------------------**

---
###         🛡 1. Firewall — контроль                         входящих соединений

**Что это:**
По умолчанию Arch ничего не блокирует.  
Если у тебя открыт порт — к нему можно подключиться.

*Самый простой вариант — `ufw`.*

---
####                       📦 Установка

``` bash
sudo pacman -S ufw
```

---
####                  🚀 Включить firewall

``` bash
sudo systemctl enable --now ufw
```

---
####    🔒 Включить правила по умолчанию

``` bash
sudo ufw default deny incoming  
sudo ufw default allow outgoing
```

**📌 Что это делает:**

- блокирует все входящие подключения
    
- разрешает исходящие

*Это безопасная базовая конфигурация.*

---
####          🌐 Открыть конкретный порт

``` bash
sudo ufw allow 22
```

**📌 Используется:**

- если нужен SSH
    
- если поднимаешь сервер

---
####                 📋 Проверить статус

``` bash
sudo ufw status verbose
```

---
###            🔑 2. SSH безопасность

**Что это:**
Если у тебя установлен `openssh` и включён `sshd` он потенциальная точка входа.

---
####                      📂 Конфиг SSH

**Файл:**

``` bash
/etc/ssh/sshd_config
```

---
####            🛑 Отключить вход под root

**Найти строку:**

``` bash
PermitRootLogin yes
```

**Изменить на:**

``` bash
PermitRootLogin no
```

**📌 Почему:**  
root — первая цель перебора паролей.

---
####         🔐 Отключить вход по паролю                                (рекомендуется)

``` bash
PasswordAuthentication no
```

**📌 Используется:**

- если настроены SSH-ключи
    
- защищает от brute-force

**После изменений:**

``` bash
sudo systemctl restart sshd
```

---
###            👤 3. sudo безопасность

**Проверка файла:**

``` bash
sudo visudo
```

**Найти строку:**

``` bash
%wheel ALL=(ALL:ALL) ALL
```

*Убедиться что она раскомментирована.*

---
####                    🔒 Таймаут sudo

**Можно изменить время действия sudo-сессии:**

``` bash
Defaults timestamp_timeout=5
```

*5 минут — нормальный баланс.*

---
###          📦 4. Обновления системы

**В Arch обновления = безопасность.**

``` bash
sudo pacman -Syu
```

**📌 Используется:**

- регулярно
    
- не откладывать на месяцы

*Arch не любит “я обновлю потом”.*

---
###   🧠 5. Проверка открытых портов

``` bash
ss -tuln
```

**📌 Используется:**

- проверить какие порты слушают
    
- убедиться что лишнего ничего не открыто

---
###  🔎 6. Проверка запущенных служб

``` bash
systemctl list-units --type=service
```

**📌 Используется:**

- найти ненужные сервисы
    
- отключить лишнее

---
###                    🧱 7. Fail2Ban                                  (защита от brute-force)

**Если сервер доступен из интернета — стоит установить.**

---
####                       📦 Установка

``` bash
sudo pacman -S fail2ban
```

---
####                      🚀 Включить

``` bash
sudo systemctl enable --now fail2ban
```

**📌 Что делает:**  
Блокирует IP после нескольких неудачных попыток входа.

---
###       🔍 8. Проверка целостности                    файлов (AIDE — базово)

``` bash
sudo pacman -S aide
```

*Используется на серверах для отслеживания изменений системных файлов.*
