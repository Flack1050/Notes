###                      Installing AUR 
---
**1️⃣ Установка git:**

```
sudo pacman -S --needed base-devel git
```


**2️⃣ Установка paru:**

```
git clone https://aur.archlinux.org/paru.git
```

```
cd paru
```

```
makepkg -si
```

```
paru --version
```


**3️⃣ Установка yay:**

```
git clone https://aur.archlinux.org/yay.git
```

```
cd yay
```

```
makepkg -si
```

```
yay --version
```
