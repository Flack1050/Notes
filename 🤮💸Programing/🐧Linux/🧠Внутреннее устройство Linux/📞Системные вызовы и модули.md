# 📞 Системные вызовы и модули ядра

Связано с [[🧠Внутреннее устройство Linux]]

Единственная дверь из программы в ядро.

## Системные вызовы — пример

```bash
strace -c ls /tmp        # посчитать, какие syscall'ы и сколько раз вызвал ls
strace ls /tmp             # построчно показать каждый syscall
```

Когда ты пишешь `print("hi")` в Python — где-то в глубине это превращается в syscall `write(1, "hi\n", 3)` — запись в файловый дескриptor 1 (stdout). Терминал, файлы, сокеты, пайпы — для ядра всё это просто файловые дескрипторы, с которыми работают одни и те же `read`/`write`.

## Монолитное ядро (а не микроядро)

Linux — **монолитное ядро**: драйверы, файловые системы, сетевой стек работают в одном адресном пространстве ядра (в отличие от микроядер типа QNX/Minix, где драйверы — отдельные userspace-процессы, общающиеся через IPC). Платится за это чуть большей потенциальной поверхностью для багов в ядре, но взамен — меньше overhead'а на переключения контекста.

При этом Linux гибкий: большая часть функциональности может грузиться/выгружаться на лету как **модули ядра**, не требуя пересборки или перезагрузки всего ядра.

```bash
lsmod                      # какие модули ядра сейчас загружены
modinfo e1000e               # инфа о модуле (например, драйвер сетевой карты)
sudo modprobe nvidia          # загрузить модуль
sudo modprobe -r nvidia        # выгрузить
uname -r                        # версия текущего запущенного ядра
```
