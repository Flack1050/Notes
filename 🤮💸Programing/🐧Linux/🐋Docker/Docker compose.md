
___
Все контейнеры описываются в одном файле `docker-compose.yml` и управляются одной командой.
- `docker compose up -d` — запустить все сервисы (бэк, фронт, БД) в фоновом 
	режиме. 
	
- `docker compose up --build` — пересобрать образы (если изменился код или 
	-`requirements.txt`) и запустить.
	
- `docker compose down` — остановить и удалить все контейнеры проекта.
	
- `docker compose down -v` — остановить проект и **стереть данные БД** (удалить
	volume).
	
- `docker compose logs -f` — смотреть логи всех контейнеров в реальном 
	времени.
	
- `docker compose logs -f backend` — смотреть логи только бэкенда.
	
- `docker compose exec backend pytest` — запустить команду (например, тесты) 
	внутри запущенного контейнера бэкенда.
