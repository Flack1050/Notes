##    📦 Arch Package Management
**----------------------------------------------------------**

---
###                       📦 Pacman

**🟢 1. -S (Sync) — Работа с репозиториями:**

``` bash
pacman -S
```

| **Аргумент** |        **Значение**         |
| :----------: | :-------------------------: |
|      -S      |          Установка          |
|     -Sy      |        Обновить базы        |
|     -Syy     | Принудительно обновить базы |
|     -Su      |       Обновить пакеты       |
|     -Syu     |      Полное обновление      |
|     -Ss      |            Поиск            |
|     -Si      |    Инфо о пакете (repo)     |
|     -Sl      | Список пакетов репозитория  |
|     -Sw      |    Скачать без установки    |
|     -Sc      |        Очистить кэш         |
|     -Scc     |     Полная очистка кэша     |

---
**🔴 2. -R (Remove) — Удаление

``` bash
pacman -R package
```

| **Аргумент** |          **Значение**           |
| :----------: | :-----------------------------: |
|      -R      |             Удалить             |
|     -Rs      |      Удалить + зависимости      |
|     -Rns     | Удалить + зависимости + конфиги |
|     -Rc      |  Удалить с зависимыми пакетами  |
|     -Ru      |  Удалить ненужные зависимости   |

---
**🔵 3. -Q (Query) — Информация о системе**

``` bash
pacman -Q
```

| **Аргумент** |       **Значение**        |
| :----------: | :-----------------------: |
|      -Q      |     Все установленные     |
|     -Qi      |        Информация         |
|     -Ql      |       Файлы пакета        |
|     -Qs      | Поиск среди установленных |
|     -Qe      |    Явно установленные     |
|     -Qd      |        Зависимости        |
|     -Qtd     |          Сироты           |
|     -Qk      |  Проверка файлов пакета   |
|     -Qm      |        AUR пакеты         |
|     -Qu      |   Пакеты с обновлениями   |

---
**🟣 4. -U (Upgrade) — Установка из файла**

``` bash
pacman -U package.pkg.tar.zst
```
*Используется для локальных пакетов.*

---
**🟡 5. -D (Database)**

|      **Аргумент**       |          **Значение**           |
| :---------------------: | :-----------------------------: |
|   -D --asdeps package   |    Отметить как зависимость     |
| -D --asexplicit package | Отметить как явно установленный |
|                         |                                 |

---
**🧠 Полезные комбинации**

``` bash
pacman -Qtdq

sudo pacman -Rns $(pacman -Qtdq)

pacman -Qdt

pacman -Qkk
```

| **Аргумент** |         **Значение**          |
| :----------: | :---------------------------: |
|    -Qtdq     |        Показать сироты        |
|     -Rns     |        Удалить сироту         |
|     -Qdt     |        Проверка сирот         |
|     -Qkk     | Проверить целостность системы |

---
**🔎 Проверка зависимостей**

``` bash
pacman -T package_name
```
*Проверить установлены ли зависимости.*

---
**📂 Список файлов репозитория**

``` bash
pacman -Fy
pacman -F filename
```
*Поиск файла в репозиториях.*

---
**📊 Размер установленных пакетов**

``` bash
pacman -Qi package | grep Size
```

###                     📦Paru и Yay

**Они повторяют структуру pacman поэтому:**

- Все `-S`
    
- Все `-R`
    
- Все `-Q`

*работают так же.*

---
**Дополнительно:**

| **Команда** |         **Значение**          |
| :---------: | :---------------------------: |
|    -Sua     |     Только AUR обновления     |
|     -Yc     | Очистка ненужных зависимостей |
|     -G      |       Скачать PKGBUILD        |
|     -Ps     |      Показать статистику      |
