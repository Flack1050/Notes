*Конструкт нужен для облегчения кода*
```python
class Cat:  
    name = None  
    age = None  
    isHappy = None  
  
    def __init__(self, name, age, isHappy):  
        self.name = name  
        self.age = age  
        self.isHappy = isHappy  
        self.get_data() # Можно добавить метод в конструкт
        
    def get_data(self):  
        print("Зовут:", self.name, "Возраст:", self.age, "Счастлив:", self.isHappy)  
  
cat1 = Cat("Барсик", 3, True)  
  
cat2 = Cat("Даун", 2, False)  
  
cat1.get_data()
```
В него легко записывать информацию
