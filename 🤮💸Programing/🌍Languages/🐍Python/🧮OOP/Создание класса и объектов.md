*Классы нужны для быстрого взаимодействия с данными объектов*
```python
class Cat: #Создание класса с именем Cat
    name = None    # 
    age = None     # Созданий полей для класса
    isHappy = None #  
    def set_data(self, name, age, isHappy):  # Метод для быстрой записи 
        self.name = name                     # полей из класса в объект
        self.age = age                       # 
        self.isHappy = isHappy  
  
    def get_data(self):  # Метод для вывода информации об объектах
        print("Зовут:", self.name, "Возраст:", self.age, "Счастлив:", self.isHappy)  
  
cat1 = Cat()  # Объект cat1 принадлежащий классу Cat
cat1.set_data("Барсик", 3, True)  # Запись значений первому объекту
  
cat2 = Cat()  
cat2.set_data("Даун", 2, False)  # И второму объекту
  
cat1.get_data() # Вывод значений первого объекта
cat2.get_data() # Вывод значений второго объекта
```
Также когда *переменная* находится в классе её называют - **Полем** также само и с
Функция - **Метод**
Переменная к которой присваивается значение класса - **Объект**
