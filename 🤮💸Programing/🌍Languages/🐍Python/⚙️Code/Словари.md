*Словарь создаётся с помощью фигурной скобки* или через метод `dict` 
```python
Country = {"code": "RU", "name": "Russian", "population": 144}  

print(Country["population"]) # При выводе по ключе будет его значение

print(Country.get("code")) # Способ вывода значения через функцию get
```
В ключ словаря можно записать кортеж, строку или число, а при `dict` ток строку


*В словаре можно перебрать ключи и их значение*
```python
Country = {"code": "RU", "name": "Russian", "population": 144}

for key, value in Country.items(): # items переборка словаря в кортеж 
    print(key, "-", value)
```


*В словаре  может быть ещё словарь*
```python
persons = {  
    "user 1": {  
        "first_name": "John",  
        "last_name": "Jopkins",  
        "age": 45,  
    },  
    "user 2": {  
        "dsffsdfsdf": "dfsfsdf"  
    }  
}  
print(persons["user 1"]["age"])
```
Таким образом можно создать некую базу данных
