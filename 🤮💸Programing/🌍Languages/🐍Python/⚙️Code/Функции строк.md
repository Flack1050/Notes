### `word = "Hello"` 

*Считает символы в строке*
```python
print(len(word))
```

*Переводит все символы в верхний регистр*
```python
print(word.upper())
```
Есть аналог - `lower`  переводит в нижний регистр (также есть `is` если его добавить он проверит строку на нужный регистр)

*Делает первый символ в верхнем а остальные в нижний*
```python
print(word.capitalize())
```

*Создание среза и шага для вывода нескольких элементов из строки*
```python
print(word[0:5:2])
```
0-начало вывода 5-конец вывода 2-шаг по символам


### `word = "football, basketball, volleyball"

*Разбивает строку на список*
```python
print(word.split())
```

*Пример использования метода split*
```python
hobby = word.split()  
print(hobby[1])
```
Здесь создана переменная *hobby* с разбитой строкой на список, и вывод 1 индекса

*Здесь пример как создать красивую строку*
```python
hobby = word.split(", ")  
  
for el in range(len(hobby)):  
    hobby[el] = hobby[el].capitalize()  
  
result = ", ".join(hobby)
print(result)
```
Метод `join` превращает список в строку
