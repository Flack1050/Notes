### `def
*Функции создаются для минимизации кода*
```python
def nums_for_win(nums): # `def` используется для создания функции 
    print(nums, end="")  
    print("!") 
  
nums_for_win(123)
```
Внутри функции можно записать любой исполняемый код.
Также в функцию можно записывать параметр тут параметр `nums` - по факту переменная которую можно создать прям в функции

*Функция может возвращать значение в ходе операции*
```python
def summa(a, b):  
    return a + b # return возвращает значение для последущей работы с ним 
  
result = summa(312, 2)  
print(result)
```
Также в функцию можно записывать сколько угодно параметров

### `lambda`
*lambda - это анонимная функция которая помещается под переменную*
```python
func = lambda x, y: x * y  
print(func(5, 2))
```
Под её записью уже подразумевается `return` и в неё можно записать только одной действие
