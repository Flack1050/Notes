### `random()`

| randint(a,b)             | возвращает случайное целое число из диапазона a-b включительно                                |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| randrange([a], b,[step]) | Возвращает случайное целое число из<br>последовательности чисел                               |
| random()                 | Возвращает случайное вещественное число из<br>диапазона 0.0-1.0                               |
| uniform(a,b)             | Возвращает случайное вещественное число из<br>диапазона а-b включительно                      |
| shuffle(list)            | Возвращает список, перемешанный случайным<br>образом                                          |
| choise(list)             | Принимает список (строку) и возвращает один<br>случайный элемент                              |
| sample(list,n)           | Принимает список (строку) и кол-во элементов,<br>а возвращает список из n случайных элементов |

### `decimal()`

```python
from decimal import *  
  
def main():  
    a = Decimal('7.1') + Decimal('8.2')  
    if a == Decimal('15.3'):  
        print('YES')  
    else:  
        print(a)  
  
  
main()
```
Decimal нужен для перевода в десятичную систему
**Переводит только из строки(с методом `float` конфликтует)**
