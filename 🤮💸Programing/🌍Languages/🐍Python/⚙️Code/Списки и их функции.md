``` Python
nums = [5, 2, 3]  
nums.append(100) # Просто вносит элемент в список  
nums.insert(2, True) # Вносит n элемент под порядковым индексом  
  
b = [5, 6, 7]  
nums.extend(b) # Добовляет в nums ещё один список в данном случаи список b  
  
nums.sort() # Сортирует порядок элементов  
nums.reverse() #Реверсирует порядок элементов  
nums.pop(1) # По умолчанию удаляет последний элемент, но если внести индекс удалит его  
nums.remove(100) # Удаляет выбранный элемент  
nums.clear() # Очищает список  
  
print(nums.count(5)) # Ищит указанный элемент и выводит его колличество если не найдёт напишет 0  
print(len(nums)) # Показывает длину списка
```


*И ещё есть кортежи*
```python
nums = (5, True, 100, 1)
```
Они создаются c помощью круглых скобок, занимают меньше памяти и не поддаются изменениям.
