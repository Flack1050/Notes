*C помощью исключений можно предотвратить фатальные ошибки*
```python
try:  
    x = int(input("Введите число"))  
    x += 5  
    print(x)  
except ValueError:  
    print("Введи число, овощь!")
else:
	print("else")
finally:
	print("finally")
```
`try` - нужен для попытки вывести какие то данные. Если ошибки нет выведется x
`except` -  существует для предотвращения фатальной ошибки и выводит пользователю указанный код
`else` - иначе, то есть если не выполнился `except` выполнится `else` 
`finally` -  выполняется не зависимо от того сработал ли код выше или нет. нужен для завершения программы и понимания пользователя
