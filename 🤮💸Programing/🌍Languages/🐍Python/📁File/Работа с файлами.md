**Файл можно: открыть, закрыть, читать и записывать в него что то*

*Запись в файл*
```python
data = input('Введите текст: ') # Запись через пользователя
  
file = open("data/text.txt", 'w')  # Создание и открытие файла в директории
  
file.write(data + '\n')  
file.write('!!!')  
  
file.close()
```

*Чтение файла*
```python
file = open("data/text.txt")  
  
print(file.read(20))
  
for line in file:  
    print(line, end='')  
  
file.close()
```
В этих примерах содержимое файла выводится в ран
