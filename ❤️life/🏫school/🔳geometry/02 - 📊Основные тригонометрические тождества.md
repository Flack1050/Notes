# Основные тригонометрические тождества

## Главное тождество (из теоремы Пифагора)
$$\sin^2 \alpha + \cos^2 \alpha = 1$$

Откуда взялось: если катеты a и b, гипотенуза c, то по Пифагору $a^2+b^2=c^2$. Разделив на $c^2$, получаем $\left(\frac{a}{c}\right)^2 + \left(\frac{b}{c}\right)^2 = 1$, а это и есть $\sin^2+\cos^2$.

Из него можно выразить:
$$\sin \alpha = \sqrt{1 - \cos^2 \alpha}, \qquad \cos \alpha = \sqrt{1 - \sin^2 \alpha}$$
(для угла от 0° до 90° знак всегда "+", корней бояться не нужно)

## Тангенс через синус и косинус
$$\tan \alpha = \frac{\sin \alpha}{\cos \alpha}$$

## Формулы приведения для смежных углов (сумма углов = 180°)
Если два угла в сумме дают 180° (например, углы при одной стороне в вписанном четырёхугольнике):
$$\sin(180^\circ - \alpha) = \sin \alpha$$
$$\cos(180^\circ - \alpha) = -\cos \alpha$$

## Синус и косинус дополнительных углов (сумма = 90°)
Если два угла в сумме дают 90° (например, два острых угла прямоугольного треугольника):
$$\sin(90^\circ - \alpha) = \cos \alpha$$
$$\cos(90^\circ - \alpha) = \sin \alpha$$

> [!tip] Почему это логично
> В прямоугольном треугольнике два острых угла всегда в сумме дают 90°. Противолежащий катет для одного угла — это прилежащий катет для другого. Поэтому синус одного угла равен косинусу второго.
