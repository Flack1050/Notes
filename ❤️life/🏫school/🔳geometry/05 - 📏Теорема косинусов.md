# Теорема косинусов

## Формулировка
Это обобщённая теорема Пифагора для любого (не только прямоугольного) треугольника:

$$c^2 = a^2 + b^2 - 2ab\cos C$$

где C — угол между сторонами a и b, а c — сторона напротив угла C.

## Связь с теоремой Пифагора
Если угол C = 90°, то $\cos 90° = 0$, и формула превращается в обычный Пифагор: $c^2=a^2+b^2$. То есть теорема косинусов — это "Пифагор с поправкой на угол".

## Когда применять
- Известны **две стороны и угол между ними** → находим третью сторону.
- Известны **три стороны** → находим любой угол (тогда формулу нужно решить относительно косинуса):

$$\cos C = \frac{a^2+b^2-c^2}{2ab}$$

## Как определить тип треугольника по этой формуле (полезный трюк)
Смотрим на знак $\cos C$:
- Если $a^2+b^2 > c^2$ → угол C острый (cos положительный)
- Если $a^2+b^2 = c^2$ → угол C прямой (это и есть Пифагор)
- Если $a^2+b^2 < c^2$ → угол C тупой (cos отрицательный)

## Пример хода решения
Дано: a=5, b=7, угол между ними C=60°. Найти c.

$$c^2 = 5^2+7^2-2\cdot5\cdot7\cdot\cos60° = 25+49-70\cdot\frac12 = 74-35=39$$
$$c=\sqrt{39}$$
