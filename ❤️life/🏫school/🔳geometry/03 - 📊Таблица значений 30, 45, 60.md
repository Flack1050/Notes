# Таблица значений синуса, косинуса, тангенса для 30°, 45°, 60°

Это единственная таблица, которую реально нужно знать наизусть в 9 классе.

| Угол | sin | cos | tan |
|---|---|---|---|
| 30° | 1/2 | √3/2 | 1/√3 = √3/3 |
| 45° | √2/2 | √2/2 | 1 |
| 60° | √3/2 | 1/2 | √3 |

## Как запомнить без зубрёжки

**Правило руки** — самый рабочий способ. Загни пальцы левой руки для углов 0°, 30°, 45°, 60°, 90° (по порядку от мизинца к большому). Номер пальца — это n (от 0 до 4). Тогда:
$$\sin(\text{угол}) = \frac{\sqrt{n}}{2}$$

Проверка: для 0° → n=0 → sin=0. Для 30° → n=1 → sin=√1/2=1/2. Для 45° → n=2 → sin=√2/2. Для 60° → n=3 → sin=√3/2. Для 90° → n=4 → sin=√4/2=1.

Косинус — то же самое, но в обратном порядке (или используй формулу $\cos\alpha = \sin(90°-\alpha)$ из [[02 - 📊Основные тригонометрические тождества]]).

## Второй способ — заметить симметрию
- Для 45° синус и косинус **равны** (√2/2), потому что треугольник равнобедренный.
- Для 30° и 60° значения синуса и косинуса **меняются местами** (1/2 ↔ √3/2), потому что это дополнительные углы (30°+60°=90°).

## Тангенс — не учи отдельно
Всегда получай через $\tan\alpha = \sin\alpha / \cos\alpha$, если забыл. Для 45° это очевидно даёт 1 (одинаковые катеты).
